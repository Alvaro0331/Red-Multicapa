# Red-Multicapa

Implementación de una red multicapa con una capa de salida y una capa oculta con n nodos

* Función de activación utilizada: _Sigmoid y su derivada_
* Implementa retropropagación (Etapa hacia adelante y hacia atrás)

<h2>Interfaz</h2>

**1.-** El usuario puede añadir puntos a una gráfica o elegir entre unas de las opciones predeterminadas.

**2.-** Elije la cantidad de nodos de la capa oculta

**3.-** Ajusta el learning rate

*(Los puntos dos y tres son opcionales de modificar, tienen valores predeterminados en caso de no querer modificarse)*
